# Инструкция по созданию нового проекта React с помощью Vite

1. Убедитесь, что у вас установлен Node.js версии 18 или выше. Проверить версию можно командой `node -v`.
2. Откройте терминал в VS Code и выполните следующую команду для создания нового проекта React:
```
npm create vite@latest my-app -- --template react
```
3. Нажмите клавишу 'Enter', чтобы запустить выполнение команды в терминале.
4. Дождитесь завершения процесса создания проекта.
5. Перейдите в папку проекта:
```
cd my-app
```
6. Установите зависимости:
```
npm install
```
7. По окончании установки вы получите сообщение об успешном создании проекта.
