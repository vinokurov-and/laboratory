# Инструкция по запуску React-приложения

1. Убедитесь, что в терминале или в командной строке вы находитесь в папке с вашим проектом React.
2. Если в терминале указан путь с директорией не вашего проекта, то используйте команду `cd <путь_к_папке_с_проектом>` для перехода в нужную директорию.
3. Когда вы окажетесь в папке с проектом React, выполните следующую команду в терминале: `npm run dev`. Эта команда запустит development-сервер.
4. После успешного запуска сервера ваше React-приложение будет доступно по адресу `http://localhost:5173` в вашем браузере.
5. Теперь вы можете внести некоторые изменения в файл `src/App.jsx`. Например, вы можете заменить существующий текст на что-то другое.
6. Когда вы сохраните изменения в файле `src/App.jsx`, development-сервер автоматически обновит страницу в вашем браузере, и внесённые изменения будут отображены на странице.
