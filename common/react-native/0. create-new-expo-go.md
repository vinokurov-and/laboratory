# Инструкция по созданию нового проекта React Native через Expo

1. Откройте терминал VS Code и выполните следующую команду, чтобы создать новое Expo-приложение:
```
npx create-expo-app@latest myApp --template blank
```

2. Перейдите в папку проекта, используя команду:
```
cd myApp
```

3. Для возможности запускать мобильное приложение через веб-браузер, установите необходимые зависимости:
```
npx expo install react-dom react-native-web @expo/metro-runtime
```
